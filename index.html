Data Cleaning

Data cleaning (also called data wrangling or preprocessing) is the first step in the data science lifecycle. It involves handling missing or inconsistent values, standardizing formats, and removing duplicate or irrelevant records.

Common steps

  • Inspect the data for missing values and outliers
  • Impute missing values using appropriate strategies (mean, median, mode)
  • Normalize or standardize numeric features as needed
  • Encode categorical variables so the model can interpret them
  • Remove duplicates and check consistency across columns

In this project, the dataset is first cleaned by standardizing column names, replacing missing values, and converting data types. The next steps are to explore relationships between features and prepare the dataset for modeling.

Exploratory Data Analysis (EDA)

EDA helps you understand the structure of the dataset and the relationships between features before training a model.

Key questions

  • How are the features distributed?
  • Which features correlate most strongly with the target (loan status)?
  • Are there imbalances or outliers that could affect model training?

Typically, you will visualize the data using histograms, bar charts, and scatter plots — and compute summary statistics (mean, median, variance, etc.). These insights guide feature engineering and modeling decisions.

Data Preprocessing

Preprocessing transforms the cleaned data into a format suitable for machine learning algorithms.

Typical preprocessing steps

  • Encode categorical variables (one-hot, ordinal encoding)
  • Scale numeric features (standardization, normalization)
  • Create derived features to expose new patterns
  • Split the dataset into training, validation, and test sets

This stage is crucial to ensure the model is trained on data that is representative, clean, and properly formatted.

Modeling

Model training takes preprocessed data and learns patterns that map inputs to the target (loan status).

Typical model workflow

  • Choose an algorithm (logistic regression, tree-based models, etc.)
  • Train the model on a training dataset
  • Validate on a holdout/validation set
  • Evaluate performance using metrics like accuracy, precision, recall, and ROC-AUC

This demo uses a logistic regression model trained on the dataset. The model output is served via the API endpoint.
